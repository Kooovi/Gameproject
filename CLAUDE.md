# Contexto para Claude

## El proyecto
Control de costos por obra para constructoras pequeñas: compara presupuesto contra gasto
real por obra y por partida. Es un proyecto de portafolio y la base de una herramienta
que se quiere probar con una constructora real. Ver `README.md` y `docs/GUIA.md`.

- Stack: Python, SQLite, pandas, Streamlit, Altair, pytest.
- Correr: `streamlit run streamlit_app.py` · Pruebas: `pytest`
- El SQL va en archivos de `sql/`, comentado. La lógica va en `costos/`; `streamlit_app.py` solo dibuja.
- Los datos de `costos/demo.py` son ficticios. No se ha probado con datos reales todavía.

## Cómo trabajar
- Español, informal, directo y corto.
- Explicar qué hace cada parte importante del código: tiene que poder defenderlo en una entrevista.
- Código simple y legible antes que ingenioso. Nombres y comentarios en español.
- Antes de construir algo grande, proponer el plan en pocos pasos y esperar el visto bueno.
- Mantener el README al día: es parte del portafolio.
- No inventar datos ni logros. Si algo no está hecho o probado, decirlo.
